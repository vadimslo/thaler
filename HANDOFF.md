# Thaler: handoff для разработчика

Это готовый шаблон «ончейн-центробанк» на Ethereum Sepolia, собранный за одну ночь. Задача на его основе: сделать проект класса Twofold ($TWO, twofold.fi) с той же структурой и тем же уровнем сайта. Спека задачи в конце файла.

## Что здесь

| Папка | Что |
|---|---|
| `contracts/` | Foundry, Solidity 0.8.26, via_ir. Шесть контрактов в `src/`, интерфейсы в `src/interfaces/`, спек механики `DESIGN.md`, 50 тестов в `test/`, деплой `script/Deploy.s.sol`, адреса живого деплоя `deployments/11155111.json`. Зависимости не вендорены: `DEPS.md` |
| `web/` | Next.js 15 static export, Tailwind v4, wagmi v2 + viem. Всё под `/app/*`. ABI и адреса синкаются `npm run sync:abi`. `e2e/testwallet.js` инжектит EIP-6963 кошелёк с приватником для сквозного теста без MetaMask |
| `bots/` | Бот активности: 5 кошельков, каждые 10 минут случайные действия, лимиты, пополнение, самопочинка (`self_heal.py` зовёт headless `claude -p`, шлёт одну строку в Telegram) |
| `bin/` | `deploy.sh [--dry]` деплой с верификацией, `publish-site.sh` сборка и пуш в ветку gh-pages |
| `docs/` | Вайтпейпер и контент-план |
| `selftest.py` | Проверка живости: контракты, владельцы, сайт, бот |
| `STATE.md`, `GOTCHAS.md`, `REPORT.md` | Как устроено, где ловушки (обязательно прочитать GOTCHAS: газ, RPC, Gemini), что упрощено |

Живой пример: https://vadimslo.github.io/thaler/app/ и https://github.com/vadimslo/thaler

## Запуск

```
cp .env.example .env            # ключ тестового деплоера, RPC, Etherscan API key
cd contracts && forge install --no-git OpenZeppelin/openzeppelin-contracts@v5.1.0 && forge install --no-git Uniswap/v4-periphery
cp -R lib/v4-periphery/lib/v4-core lib/v4-core && forge build && forge test
cd ../web && npm ci && npm run sync:abi && npm run build
../bin/deploy.sh --dry          # потом без --dry
```

Боты: `.env.bots` с `BOT_PK_1..5`, `python3 bots/activity.py --fund`, потом LaunchAgent (пример plist в `bots/com.vadim.thaler-activity.plist`). Telegram и `claude` в `self_heal.py` завязаны на пути владельца, поправить под себя или выключить.

## Уроки, которые стоили времени

- Оценка газа с публичного Sepolia RPC занижена на этих путях: во фронте буфер 50% и минимальные лимиты на функцию (`web/src/hooks/useTx.ts`), в боте лимиты явные.
- `forge script` без `--broadcast` тоже пишет `deployments/*.json`: удалять перед реальным деплоем.
- Посад ликвидности и инициализация пула в одной транзакции, иначе пустой пул фронтранится.
- GitHub Pages: сборку пушить в ветку `gh-pages`, Actions выключить, иначе письма об ошибках.
- Сквозной тест фронта только с реальными транзакциями через инжект кошелька, мок-кошелёк ловит не всё.

## Задача: проект класса Twofold на этом шаблоне

Суть Twofold: двойная доходность ликвидности на Uniswap v4. Простаивающая котируемая сторона пула лежит в ERC-4626 лендинг-хранилище и зарабатывает процент; в момент свапа хук достаёт ровно нужную ликвидность, берёт комиссию и возвращает остаток. Вкладчик получает и лендинг-доход, и комиссии с одного депозита. Плюс свой токен со стейкингом.

1. Контракты на Sepolia. Движок DualPool брать из открытого репо Uniswap `v4-hooks-public` неизменённым (аудирован). Обвязка (реестр пулов, аллоулист хранилищ, заппер, токен, стейкинг) есть в MIT-репо `github.com/twofoldfi/twofold-contracts`: форкать и адаптировать. На Sepolia нет USDG и токенизированных акций: задеплоить мок-стейбл USD, три мок-акции (AAPL, TSLA, NVDA) с настраиваемой ценой и мок ERC-4626 хранилище с фиксированным APY, на сайте честно подписать как тестовые. Пулы: ETH/USD и три акции/USD. Токен: кап 1 млрд, стейкинг с кулдауном, комиссии протокола стейкерам. Тесты на форке, аудит с PoC, контракты верифицированы с первого дня, все параметры опубликованы. Мейннет только после внешнего аудита.
2. Сайт это апка без отдельного лендинга, оболочка как здесь (боковое меню, хлебные крошки, статус-строка, хиро-карточки, живая лента). Страницы: Home, Pools (APY лендинга и комиссий, TVL, депозит и вывод), Swap, Stake, Activity, Protocol Info (Overview, Token, Vaults, Params, Contracts, Whitepaper), Updates. Каждая цифра с чейна, обновление раз в 12 секунд. Иллюстрации в одном стиле или никакие: плохая картинка хуже пустой карточки.
3. Вайтпейпер: тон монетарного документа, без обещаний доходности, без длинных тире и восклицаний, полная таблица параметров тестнет/мейннет.
4. Бот активности как здесь: депозиты, выводы, свапы, стейкинг с 5 кошельков, чтобы апка не выглядела мёртвой. Лимиты, пополнение, самопочинка.
5. Сквозной тест: каждая кнопка каждой страницы проходит реальной транзакцией со статусом успех.
6. Ченджлог на сайте с датами, контент-план на две недели: без хэштегов, без длинных тире, максимум один эмодзи, только факты.
7. Имя: два-три варианта со свободными доменами, рабочее ставится сразу, замена одной командой.

Порядок: сначала план на страницу, потом сборка до конца. Сухой прогон перед деплоем. В конце: ссылка на апку, скрины четырёх страниц, список упрощений.
